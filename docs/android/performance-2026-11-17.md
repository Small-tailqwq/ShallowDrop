# 长上下文、分支与包体验证

本次使用 `cursor/plugins` 中的 pstack 工作流进行基准测量、先复现后修复及独立审查。拉取版本为 `3fa33bb0f927bea2ccacd48a3cfda95145fb6bae`，本地位于 `tmp/cursor-plugins/pstack`。

## 聊天性能

聊天缓存使用 `ConversationSnapshot`：保留全部版本的轻量树结构，仅载入当前路径正文。Room v2 将父节点和选中子节点存为独立列，通过覆盖索引查询树，再分批读取选中的正文。完整历史仍留在数据库中。

生成期间缓存节点位置和兄弟版本编号，复用未变化的 `TurnView`。启动时不再扫描全部会话正文，中断回复在打开相应路径时收尾。v1 数据库首次升级需要逐条回填树字段。

### 冷启动首帧

在 MuMu Android 15 / API 35、x86_64 模拟器上，用上述同一规模的 7,001 条消息、331,212,787 字节历史数据补测冷启动。应用 Java 堆上限为 192 MiB。独立测试包使用相同 applicationId 和签名，前后覆盖安装保留同一个数据库及设置；入口为已完成设置的默认聊天页，历史会话未打开。

两组均为启用 R8 和资源缩减的非 debuggable release 包。基线在当前生产源码上恢复旧启动函数实际执行的全量会话读取和未完成状态检查；样本的回复全部完成。其他生产代码、资源和 Room v2 数据库均相同，因此本对照衡量移除启动全量扫描的影响，不包含数据库迁移。

每次安装后执行 `cmd package compile --reset`，再 `am force-stop`，确认进程退出后用 `am start -W` 启动单个 MainActivity，取 `TotalTime`。这是 Android 的[首帧显示时间（TTID）](https://developer.android.com/topic/performance/vitals/launch-time)，当前应用的首帧可能先绘制空 Surface，不等于聊天页全部内容可交互的时间。操作系统文件缓存未清空。剔除一组预跑后，按旧、新交替执行六组正式测量；计时期间未运行构建或 profiler。

首帧中位数只相差 1 ms，逐轮差异方向不一致，未测到稳定的首帧提速。每次首帧后固定观察 15 秒，并检查进程、聊天页和双方相同的后台阶段诊断日志：

| 检查 | 旧启动扫描 | 当前实现 |
| --- | ---: | ---: |
| `COLD` / `Status: ok` | 6/6 | 6/6 |

| 未捕获的致命异常 | 0/6 | 0/6 |

旧扫描在约 2.2 秒后于 `CursorWindow.getString` 读取正文时触发 `OutOfMemoryError`，由原有 `runCatching` 捕获，应用进程仍然存活。当前实现不再执行该全量扫描，消除了此样本下的后台内存不足；没有把扫描耗时计作首帧耗时。

实验前后按 `seq` 顺序对消息 JSON 的 UTF-8 字节连续计算 SHA256，行数、字节数和哈希均一致：`096900005f5a14ee48dcaa211eb55263980357bbed57f3f20c227c59406be3eb`。独立的只读复核测试通过。正式逐次结果、启动输出、日志、UI XML 和哈希记录位于 `tmp/startup/runs/`、`tmp/startup/fixture-before.txt` 与 `tmp/startup/fixture-after.txt`；测速脚本和 APK 位于 `tmp/startup/`。

## 缺陷与回归

- 搜索按界面规则拼接相邻正文块，修复跨块关键词漏查及换行误命中；查询分批读取，结果只保留命中附近的预览。
- 归档 JSON 使用流解码，修复超过 16 MiB 的会话可以导出却无法导回的问题。5,000 份、每份 4,096 字符的回答已完成真实导出导入，恢复 5,001 条消息；会话 JSON 为 21,624,290 字节。
- 导出与导入统一采用 512 MiB 总限制。导入仍会建立单个会话的 JSON 树及消息模型，尚不是内存有界的逐消息导入。
- 回复操作栏自动换行，5,001 个版本时“重新生成”等按钮仍可操作。
- 异步读取合并期间发生的重命名和附件上传更新，避免旧快照覆盖新标题、文件 ID，并验证重建聊天引擎后不会重复上传。

完整 JVM / Robolectric 测试 458 项通过，无失败、错误或跳过；`lintDebug` 通过，0 个错误、10 个警告；release 构建和 Android 大数据测试通过。迁移回归覆盖 v1 消息、附件引用及未完成导入状态，分支回归覆盖独立续聊、嵌套编号、摘要和导航行为。
